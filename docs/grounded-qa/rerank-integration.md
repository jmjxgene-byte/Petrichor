# 文档索引重排接入

2026-09-09，MVP仅在版本化本地文档索引路径接入外部重排，不改变GeneOps RPC、旧知识库范围或生产配置。

## 配置与权限

- `PETRICHOR_DOC_RERANK_ENABLED=false` 默认关闭。
- 显式启用后，`PETRICHOR_DOC_RERANK_MODEL` 首期只接受已探针验证的 `BAAI/bge-reranker-v2-m3`。
- 按请求用户查询EMBEDDING绑定，并校验binding/model/provider/credential四层user_id、模型类型与启用状态；仅接受硅基流动及固定HTTPS端点。无配置、不兼容端点、非空自定义headers、模型不符均不发请求，降级本地。
- Key从原加密凭证在进程内解密，不复制到env、数据库新字段、浏览器或日志。没有新增迁移。

## 执行与失败边界

RRF合并后的最多20个候选进入重排，查询不超过2000字符；标题/摘要/正文分别截取300/600/1200字符，复用已有重排器。重排共用检索8秒总预算，配置读取及HTTP合计最多1500ms，不足250ms时跳过；不自动重试。仅传本轮范围内本地候选，不扩库或读取GeneOps正文。

共享HTTP重排器增加已取消请求拒绝、禁止重定向、return_documents=false、128KiB响应限制，以及结果数量、唯一候选index、整数范围和有限分数检查。缺失/重复/越界结果不再静默接受。外部失败只返回`rerank_unavailable`，预算不足为`rerank_budget_exhausted`，均沿用本地词法重排；用户取消仍向上抛出，不伪装降级成功。搜索将降级码返回既有degraded字段，保留generation/passage/hash引用身份。

## 验证与未完成

Mock HTTP/真实查询谓词测试覆盖关停零调用、四层归属、固定目标、配置失配、超过20候选、超时、取消、错误不重试与日志安全，以及搜索入口降级传播。完整回归1504通过/40既有跳过；类型/Lint/build通过；默认关闭下原生PG75项通过，隔离资源清理成功。本节点不新增真实模型调用；上个节点的两次合成探针不能替代此集成的真实端到端验收。

尚需独立批准有限索引canary、模型用量及Staging接线，完成固定60题、人工引用支持与性能检查后才部署完整MVP。当前UI不变，生产未启用，不能称为线上重排已生效。
