# 宿主控制器：本地故障注入验收

2026-09-09，`canary-host-controller.ts`复用现有call journal和artifact spool，增加单项调度与只恢复模式。模块不访问SSH、数据库或provider，使用显式注入的runtime port；尚未接入真实服务器命令适配器。

宿主初始化使用排他目录，绑定执行身份、运行时身份、代码/计划/请求集/provider profile哈希、调用数和截止时间。每项先持久化dispatch，再允许executeOne；执行失败保留dispatch且不自动重发，即使运行时仍报告not_started。recover永不执行模型入口，只取回已完成结果、补缺失块并重发幂等ACK。前项宿主收据和ACK未完整验证时不得推进后项。未知结果、身份变化、块损坏或授权过期均阻止新执行。

8项本地测试覆盖正常推进、已完成结果恢复、执行返回丢失、派发前中断、取块/ACK丢失、结果未知、损坏块、权限/身份/期限及并发排他。测试使用本地真实文件journal和合成字节；未模拟操作系统断电或真实网络断线。全量1590通过、40项既有跳过；typecheck、lint、build与diff检查通过，既有大chunk构建警告保留。

下一步是将runtime port接至受控命令适配器，核验运行时实例与入口SHA，再执行零服务端到端演练。适配器必须验证响应格式和输出上限，不加载或导出凭证；宿主目录必须持久化且执行身份不能重建复用。此模块测试不代表真实canary、检索质量或MVP验收通过，不能据此开启生产模型任务或部署。
